# v0.3.0 Service Packages Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move every SDK service into its own public package with one method shape, `Method(ctx, *Input) (*Output, error)`, and share one login and project discovery per `vngcloud.Config`. No new API coverage.

**Architecture:** `internal/core.Config` becomes an opaque handle around one `*core.Client` (token, transport, project cache); root `vngcloud` aliases it and never imports a service package. Each service moves from `internal/<svc>` to `<svc>/` and gets `New(cfg vngcloud.Config) *Client`. The old `vngcloud.NewClient` and `internal/sdk` shrink one service per task and are deleted in Task 10, so every commit builds and passes `make check`.

**Tech Stack:** Go 1.27.1, standard library only, golangci-lint 2.13.2.

**Spec:** `docs/design/sdk-and-cli.md`, section "SDK" and the `v0.3.0` release row. Error codes, `LoginError`, `CredentialsProvider.Invalidate`, and `LoadConfig` belong to later releases.

## Global Constraints

- Work on branch `v0.3.0` from `master`. The manager creates it and makes every commit; workers do not run git write commands.
- Every commit passes `make check` (tests, vet, golangci-lint at 0 issues, lengths: Markdown ≤ 450 lines, non-test Go ≤ 700 lines).
- Standard library only. No new dependencies in `go.mod`.
- Root package never imports a service package; `internal/core` never imports root. Service packages may import each other (`network` imports `compute`).
- Operation signature: `func (c *Client) Op(ctx context.Context, in *OpInput) (*OpOutput, error)`. Every operation has its own `OpInput` type, even when empty (`type ListGPUImagesInput struct{}`). A nil `in` is valid when no field is required.
- Input and Output structs have no JSON tags. Resource models (`Server`, `VPC`, ...) keep their API JSON tags unchanged.
- A required Input field has tag `vngcloud:"required"`. Each operation calls `core.CheckRequired("<pkg>.<Op>", in)` first and returns its error before any request.
- Get outputs are structs with one named field: `GetServerOutput{Server Server}`. Lists with page metadata return `core.PagedList[T]`; lists without it return `core.List[T]`. Declare outputs as aliases: `type ListServersOutput = core.PagedList[Server]`.
- `transport.Request.Operation` is `"<package>.<Method>"`, lowercase package: `"compute.GetServer"`.
- Service type is `Client` (not `Service`); constructor `New(cfg vngcloud.Config) *Client` stores `core.ClientOf(cfg)`.
- Fixtures in `testdata/` do not change. Test fixture paths become `../testdata/...` (one level up from `<svc>/`).
- Code comments explain constraints only. No plan or task IDs in code, tests, or docs.

## Review Focus

- Zero-value `vngcloud.Config{}` passed to `New`: every call returns an error wrapping `vngcloud.ErrInvalidConfig`, never a panic. Test in Task 1.
- `nil` Input to an operation with a required field: error wrapping `vngcloud.ErrInvalidInput` that names the field, no request sent. Test in Task 2 and each service task.
- Two service clients from one Config discover the project once, even when called concurrently. Test in Task 1 (`-race`).
- `APIError.Operation` uses the `<package>.<Method>` form, which the CLI prints. Test in Task 2.
- A static-token Config never attempts IAM login and needs no IAM fields. Test in Task 1.

```go
package core

import (
	"fmt"
	"reflect"
)

// CheckRequired returns an error wrapping ErrInvalidInput for the first field
// tagged vngcloud:"required" that holds its zero value. A nil pointer counts
// as all fields empty. in must be a pointer to a struct.
func CheckRequired(op string, in any) error {
	v := reflect.ValueOf(in)
	t := v.Type().Elem()
	for i := range t.NumField() {
		f := t.Field(i)
		if f.Tag.Get("vngcloud") != "required" {
			continue
		}
		if v.IsNil() || v.Elem().Field(i).IsZero() {
			return fmt.Errorf("%w: %s requires %s", ErrInvalidInput, op, f.Name)
		}
	}
	return nil
}
```

```go
// Config is a resolved configuration built by NewConfig. Every service client
// built from one Config shares its token and project discovery, so a program
// logs in once; two logins inside one TOTP window would fail.
type Config struct {
	client *Client
}

// NewConfig builds a Config from options only.
func NewConfig(opts ...Option) (Config, error) {
	c, err := newClient(opts...)
	if err != nil {
		return Config{}, err
	}
	return Config{client: c}, nil
}

func (c Config) Region() string { return ClientOf(c).Region() }

// Authenticate logs in now, so credential errors surface before the first call.
func (c Config) Authenticate(ctx context.Context) error { return ClientOf(c).Authenticate(ctx) }

// ClientOf returns the shared client. A zero Config yields a client whose
// calls fail with ErrInvalidConfig.
func ClientOf(c Config) *Client {
	if c.client == nil {
		return &Client{err: fmt.Errorf("%w: Config was not built by NewConfig", ErrInvalidConfig)}
	}
	return c.client
}
```

```go
package dns

import (
	"context"
	"net/url"
	"time"

	"danny.vn/vngcloud"
	"danny.vn/vngcloud/internal/core"
	"danny.vn/vngcloud/internal/routes"
	"danny.vn/vngcloud/internal/transport"
)

// Client calls the vDNS API.
type Client struct {
	c *core.Client
}

func New(cfg vngcloud.Config) *Client {
	return &Client{c: core.ClientOf(cfg)}
}

type ListHostedZonesInput struct {
	Name string
}

type ListHostedZonesOutput = core.PagedList[HostedZone]

func (c *Client) ListHostedZones(ctx context.Context, in *ListHostedZonesInput) (*ListHostedZonesOutput, error) {
	q := url.Values{}
	if in != nil && in.Name != "" {
		q.Set("name", in.Name)
	}
	var resp listHostedZonesResponse
	if err := c.c.DoJSON(ctx, transport.Request{
		Operation: "dns.ListHostedZones",
		Method:    "GET",
		URL:       c.url([]string{"dns", "hosted-zone"}, q),
		OK:        []int{200},
	}, &resp); err != nil {
		return nil, err
	}
	return core.NewPagedList(resp.ListData, resp.Page, resp.PageSize, resp.TotalPage, resp.TotalItem), nil
}

type GetHostedZoneInput struct {
	HostedZoneID string `vngcloud:"required"`
}

type GetHostedZoneOutput struct {
	HostedZone HostedZone
}

func (c *Client) GetHostedZone(ctx context.Context, in *GetHostedZoneInput) (*GetHostedZoneOutput, error) {
	if err := core.CheckRequired("dns.GetHostedZone", in); err != nil {
		return nil, err
	}
	var resp struct {
		Data HostedZone `json:"data"`
	}
	if err := c.c.DoJSON(ctx, transport.Request{
		Operation: "dns.GetHostedZone",
		Method:    "GET",
		URL:       c.url([]string{"dns", "hosted-zone", in.HostedZoneID}, nil),
		OK:        []int{200},
	}, &resp); err != nil {
		return nil, err
	}
	return &GetHostedZoneOutput{HostedZone: resp.Data}, nil
}
```
